# AI Governance Tracker

Automated intelligence tracking FTC AI enforcement actions, Congressional AI legislation, bar ethics guidance, ABA guidance, and EU AI Act developments. Built by RN Collins, Aloha AI Consulting.

**Live:** https://aloha-ai-governance.vercel.app

## Repository contents

`api`, `package.json`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
